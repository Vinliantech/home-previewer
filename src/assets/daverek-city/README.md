# Daverek City — Life Camp, Abuja

Drop the renders for this coming-soon project straight into this folder. They
are picked up automatically: no code change, no import to add.

- **Accepted:** `.jpg`, `.jpeg`, `.png`, `.webp`
- **Order:** filenames sort naturally, so name them `01-…`, `02-…` to control
  the sequence. The **first** image becomes the cover on the properties grid
  and the hero of the detail page.
- **Empty is safe:** with no images here the card shows the generic Kay-Steph
  hero image and no gallery section renders.

Keep each file under ~400 KB (roughly 1600 px on the long edge) — these ship
to every visitor.
