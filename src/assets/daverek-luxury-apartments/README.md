# Daverek Luxury Apartments — Katampe

A 3-bedroom luxury apartment development in Katampe, available at ₦130M.
This is a **separate project** from Daverek Apartment (Mbora) — do not mix
their renders.

Drop renders straight into this folder — picked up automatically, no code change.

- **Accepted:** `.jpg`, `.jpeg`, `.png`, `.webp`
- **Order:** filenames sort naturally, so name them `01-…`, `02-…`. The first
  image becomes the project-card cover and the top of the detail page.
- **Empty is safe:** with no images the card falls back to the hero placeholder
  and the gallery section is hidden.

Keep each file under ~400 KB. Export at roughly 1600 px on the long edge.
